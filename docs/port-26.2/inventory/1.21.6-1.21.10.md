Scope: vanilla API changes described in the NeoForged primers for these five versions, checked against Capsule at
commit `5cebb7c` (Minecraft 1.21.1). Paths are relative to the repository root.

Reading conventions:

* The Capsule code is still in its **1.21.1 shape**. A primer's "old" API is the 1.21.5 (or 1.21.8) API, so some
  locations below also need changes from earlier slices (1.21.2, 1.21.4, 1.21.5) first. When that happens it says
  *(earlier slice)*. The snippets give the **1.21.6–1.21.10 target form**.
* *(later slice)* means the API is known or likely to change again in 1.21.11 / 26.1 / 26.2. Re-check it there.
* "Verify" marks a detail not spelled out in the primer, taken from knowledge of the vanilla/loader code. Confirm it
  against the decompiled sources (or let the compiler say) before relying on it.

## Part 1: 1.21.5 → 1.21.6 (`1.21.6.md`)

### 1.1 GUI Changes › Logic Changes: `drawString` colors must carry alpha

*What changed:* `GuiGraphics#drawString` / `drawCenteredString` / every `draw*String` now reads the int color as
**ARGB**. An alpha of 0 means the text is not drawn. `0xFFFFFF` is now invisible.

*Affected:*
- `common/src/main/java/capsule/gui/LabelGui.java:107`: `guiGraphics.drawCenteredString(this.font, this.title, this.width / 2, 70, 16777215);`

*Do:* `guiGraphics.drawCenteredString(this.font, this.title, this.width / 2, 70, 0xFFFFFFFF);`
(or `ARGB.opaque(0xFFFFFF)` / `CommonColors.WHITE`).

*Nothing else in the GUI rework touches Capsule.* `LabelGui#render` only calls `super.render` and
`textInput.render` and never `renderBackground`. In 1.21.6, calling `renderBackground` inside `render` would hit
"blur once per frame". `HoverEnchantmentScreen` (`common/src/gametest/java/capsule/clientsmoke/Showcase.java:614`)
and `HoverInventoryScreen` (`common/src/gametest/java/capsule/clientsmoke/ClientSmokeTest.java:802`) only forward to
`super.render`, so they need no change in this slice. Capsule has no tooltip components, HUD drawing, `drawSpecial`,
`pose()` use, `RenderType` GUI calls or picture-in-picture.

### 1.2 Blaze3d Changes › `RenderSystem` list: `setShaderColor` / `getShaderColor` removed

*What changed:* the shader color is no longer global state. It is written per draw into the `DynamicTransforms`
UBO (`ColorModulator`). `RenderSystem.setShaderColor(float,float,float,float)` and `getShaderColor()` are gone.

*Affected* (dead code, no callers. `grep -rn pushColor\|popColor` finds only the definitions):
- `common/src/main/java/capsule/client/RendererUtils.java:132-150` (`prevColor`, `pushColor`, `popColor`)

*Do:* delete `prevColor`, `pushColor` and `popColor`. In the same file `doOverlayPrologue/Epilogue` and
`doWirePrologue/Epilogue` (lines 22-43) use `RenderSystem.disableDepthTest/enableBlend/defaultBlendFunc/setShader/
disableCull/lineWidth`, which were removed in an *(earlier slice)* (1.21.5). They have no callers either (only a
commented-out call at `CapsulePreviewHandler.java:313`), so delete them too. Keep `doPositionPrologue/Epilogue`,
`drawCube`, `drawPlane*` and `drawCapsuleCube`.

### 1.3 Blaze3d Changes › `ByteBufferBuilder` takes a long max capacity, `exactlySized`

*What changed:* `ByteBufferBuilder` gained a `long` maximum capacity and the static factory
`ByteBufferBuilder.exactlySized(int)`, which vanilla uses for its fixed buffers: the maximum equals the initial size.

*Affected:*
- `common/src/main/java/capsule/client/render/CapsuleTemplateRenderer.java:56,57,59`

*Do:* **keep the growable one-argument constructor** `new ByteBufferBuilder(size)`, which still compiles. Do **not**
switch the two ghost buffers to `exactlySized`. A large template (up to 31³ blocks) writes far more than 262 144 bytes
into one batch, and an exactly-sized builder throws once it is full. Verify that the one-argument constructor still
grows up to the default maximum. If it no longer does, use the two-argument `(initial, maxCapacity)` form with a large
max.

### 1.4 ChunkSectionLayers + `RenderType`/`RenderStateShard` list: Capsule's custom ghost render types

*What changed (this slice):*
- `RenderType#translucent`, `getRenderTarget`, `getRenderPipeline` and `chunkBufferLayers` are removed. Chunk layers
  are now `ChunkSectionLayer`.
- `RenderStateShard$TextureStateShard` no longer takes a blur `TriState`.
- `RenderType.debugLine`, the GUI render types and others are removed (Capsule uses none of them).
- `RenderPipelines` and pipeline snippets are the way to describe shaders, blend, depth, cull and color/depth write.
  This started in 1.21.5 *(earlier slice)*. 1.21.6 adds UBO uniforms (`DynamicTransforms`, `Projection`, `Fog`,
  `Globals`), which `RenderType#draw` fills automatically for immediate-mode draws.

*Affected:*
- `common/src/main/java/capsule/client/render/CustomRenderType.java:12-43` (whole class)
- `common/accesstransformer.cfg:3-4` and `fabric/src/main/resources/capsule.accesswidener:4-5`: the `RenderType.create`
  descriptor
- `common/src/main/java/capsule/client/render/CapsuleTemplateRenderer.java:54-59,84-86,111` (users of the types)

**Target design for 1.21.6–1.21.10.** This supersedes whatever the 1.21.5 slice produced for these files, but uses
the same API family:

```java
package capsule.client.render;

import capsule.CapsuleMod;
import com.mojang.blaze3d.pipeline.BlendFunction;
import com.mojang.blaze3d.pipeline.RenderPipeline;
import com.mojang.blaze3d.platform.DepthTestFunction;
import net.minecraft.client.renderer.RenderPipelines;
import net.minecraft.client.renderer.RenderStateShard;
import net.minecraft.client.renderer.RenderType;
import net.minecraft.resources.ResourceLocation;

/**
 * Ghost blocks are drawn twice: GHOST_DEPTH keeps the nearest ghost surface of each pixel (depth only, cutout),
 * then GHOST blends only that surface over the world (LEQUAL, no depth write).
 * Abstract: RenderType has abstract members since 1.21.5; this class only exists to reach the protected shards.
 */
public abstract class CustomRenderType extends RenderType {
    private CustomRenderType(String name, int size, boolean crumbling, boolean sort, Runnable setup, Runnable clear) {
        super(name, size, crumbling, sort, setup, clear);   // verify RenderType ctor signature in 1.21.6-1.21.10
    }

    public static final RenderPipeline GHOST_DEPTH_PIPELINE = RenderPipelines.register(
            RenderPipeline.builder(RenderPipelines.TERRAIN_SNIPPET)          // core/terrain, BLOCK format, QUADS, Sampler0+2
                    .withLocation(ResourceLocation.fromNamespaceAndPath(CapsuleMod.MODID, "pipeline/ghost_depth"))
                    .withShaderDefine("ALPHA_CUTOUT", 0.1F)                  // what RenderPipelines.CUTOUT does
                    .withCull(false)
                    .withColorWrite(false)                                    // old COLOR/DEPTH write mask = DEPTH_WRITE
                    .withDepthWrite(true)
                    .withDepthTestFunction(DepthTestFunction.LEQUAL_DEPTH_TEST)
                    .build());

    public static final RenderPipeline GHOST_PIPELINE = RenderPipelines.register(
            RenderPipeline.builder(RenderPipelines.TERRAIN_SNIPPET)
                    .withLocation(ResourceLocation.fromNamespaceAndPath(CapsuleMod.MODID, "pipeline/ghost"))
                    .withBlend(BlendFunction.TRANSLUCENT)
                    .withCull(false)
                    .withDepthWrite(false)                                    // old COLOR_WRITE mask
                    .withDepthTestFunction(DepthTestFunction.LEQUAL_DEPTH_TEST)
                    .build());

    public static final RenderType GHOST_DEPTH = create("capsule:ghost_depth", 262144, false, false, GHOST_DEPTH_PIPELINE,
            CompositeState.builder()
                    .setLightmapState(LIGHTMAP)
                    .setTextureState(BLOCK_SHEET_MIPPED)
                    .setLayeringState(VIEW_OFFSET_Z_LAYERING)
                    .createCompositeState(false));

    public static final RenderType GHOST = create("capsule:ghost", 262144, false, false, GHOST_PIPELINE,
            CompositeState.builder()
                    .setLightmapState(LIGHTMAP)
                    .setTextureState(BLOCK_SHEET_MIPPED)
                    .setLayeringState(VIEW_OFFSET_Z_LAYERING)
                    .createCompositeState(false));
}
```

### 1.5 Generic Encoding and Decoding: `ValueInput` / `ValueOutput` replace NBT in entity and block entity save/load

*What changed:* `BlockEntity#saveAdditional(CompoundTag, HolderLookup.Provider)` became `saveAdditional(ValueOutput)`,
and `loadAdditional(CompoundTag, Provider)` became `loadAdditional(ValueInput)`. `BlockEntity#loadWithComponents` now
takes a `ValueInput`. `Entity#save/saveWithoutId/load/addAdditionalSaveData/readAdditionalSaveData` take
`ValueOutput`/`ValueInput`. `EntityType.create/by/loadEntityRecursive` take a `ValueInput`. Bridges:
`TagValueOutput.createWithContext(ProblemReporter, HolderLookup.Provider)` → `buildResult()` gives a `CompoundTag`, and

(they wrap TagValue* internally; verify).

import net.minecraft.client.renderer.state.CameraRenderState;
import net.minecraft.core.BlockPos;
import net.minecraft.world.phys.AABB;
import net.minecraft.world.phys.Vec3;
import org.jetbrains.annotations.Nullable;

public class CaptureBER implements BlockEntityRenderer<BlockEntityCapture, CaptureBER.State> {

    public static class State extends BlockEntityRenderState {
        int size;
        int color;
        double time;
    }

    private double time = Math.random() * 10000;

    public CaptureBER(BlockEntityRendererProvider.Context ctx) {
    }

    @Override
    public State createRenderState() {
        return new State();
    }

    @Override
    public void extractRenderState(BlockEntityCapture be, State state, float partialTick, Vec3 cameraPos,
                                   @Nullable ModelFeatureRenderer.CrumblingOverlay crumbling) {
        BlockEntityRenderer.super.extractRenderState(be, state, partialTick, cameraPos, crumbling);
        time += partialTick;                      // was done per frame in render()
        state.size = be.getSize();
        state.color = be.getColor();
        state.time = time;
    }

    @Override
    public void submit(State state, PoseStack poseStack, SubmitNodeCollector collector, CameraRenderState camera) {
        if (state.size == 0) return;
        int extendSize = (state.size - 1) / 2;
        BlockPos offset = Spacial.getAnchor(BlockPos.ZERO, state.blockState, state.size);
        AABB box = Spacial.getBB(offset.getX(), offset.getY(), offset.getZ(), state.size, extendSize);
        collector.submitCustomGeometry(poseStack, RenderType.lines(),
                (pose, consumer) -> CapsulePreviewHandler.renderRecallBox(pose, state.color, box, consumer, state.time));
    }

    @Override
    public boolean shouldRenderOffScreen() {
        return true;
    }

    /** NeoForge IBlockEntityRendererExtension#getRenderBoundingBox (verify it still takes the block entity in 21.9). */
    public AABB getRenderBoundingBox(BlockEntityCapture blockEntity) {
        return blockEntity.getBoundingBox();
    }
}
