Source: NeoForged primer `primers/1.21.11.md` (read in full, 3173 lines). Repo checked: the repository root at commit `5cebb7c`

## 1. The Rename Shuffle — `ResourceLocation` → `Identifier`

  `RenderType.create(String name, RenderSetup setup)`.
- All vanilla types moved from `RenderType` static methods to `net.minecraft.client.renderer.rendertype.RenderTypes`
  (`RenderType.lines()` → `RenderTypes.lines()`, `RenderType.debugQuads()` → `RenderTypes.debugQuads()`,

```java
package capsule.client.render;

import com.mojang.blaze3d.pipeline.RenderPipeline;
import com.mojang.blaze3d.platform.DepthTestFunction;
import com.mojang.blaze3d.pipeline.BlendFunction;
import net.minecraft.client.renderer.RenderPipelines;
import net.minecraft.client.renderer.rendertype.LayeringTransform;
import net.minecraft.client.renderer.rendertype.RenderSetup;
import net.minecraft.client.renderer.rendertype.RenderType;
import net.minecraft.client.renderer.texture.TextureAtlas;
import net.minecraft.resources.Identifier;

public final class CustomRenderType {
    public static final int GHOST_BUFFER_SIZE = 262144;

    // depth only: keeps the nearest ghost surface of each pixel
    public static final RenderPipeline GHOST_DEPTH_PIPELINE = RenderPipeline.builder(/* snippet of RenderPipelines.CUTOUT_BLOCK */)
            .withLocation(Identifier.fromNamespaceAndPath("capsule", "pipeline/ghost_depth"))
            .withCull(false)
            .withDepthTestFunction(DepthTestFunction.LEQUAL_DEPTH_TEST)
            .withColorWrite(false, false)
            .withDepthWrite(true)
            .build();

    // colour only: blends that surface over the world
    public static final RenderPipeline GHOST_PIPELINE = RenderPipeline.builder(/* snippet of RenderPipelines.TRANSLUCENT_MOVING_BLOCK */)
            .withLocation(Identifier.fromNamespaceAndPath("capsule", "pipeline/ghost"))
            .withBlend(BlendFunction.TRANSLUCENT)
            .withCull(false)
            .withDepthTestFunction(DepthTestFunction.LEQUAL_DEPTH_TEST)
            .withColorWrite(true, true)
            .withDepthWrite(false)
            .build();

    public static final RenderType GHOST_DEPTH = RenderType.create("capsule:ghost_depth",
            RenderSetup.builder(GHOST_DEPTH_PIPELINE)
                    .withTexture("Sampler0", TextureAtlas.LOCATION_BLOCKS /*, sampler, see §7 */)
                    .useLightmap()
                    .setLayeringTransform(LayeringTransform.VIEW_OFFSET_Z_LAYERING)
                    .bufferSize(GHOST_BUFFER_SIZE)
                    .createRenderSetup());

    public static final RenderType GHOST = RenderType.create("capsule:ghost",
            RenderSetup.builder(GHOST_PIPELINE)
                    .withTexture("Sampler0", TextureAtlas.LOCATION_BLOCKS /*, sampler, see §7 */)
                    .useLightmap()
                    .setLayeringTransform(LayeringTransform.VIEW_OFFSET_Z_LAYERING)
                    .bufferSize(GHOST_BUFFER_SIZE)
                    .createRenderSetup());
}
```

## 7. Oh Hey, Another Rendering Rewrite — The Separation of Samplers

**What changed.** Address/filter modes moved from `GpuTexture` to `GpuSampler`. Samplers come from
`RenderSystem.getSamplerCache().getSampler(AddressMode u, AddressMode v, FilterMode min, FilterMode mag, boolean useMipmaps)`
(also `getClampToEdge(FilterMode)`, `getRepeat(...)`), or `GpuDevice#createSampler`. `RenderPass#bindTexture` takes a
`GpuSampler`. `GpuTexture#setTextureFilter/setAddressMode/useMipmaps`, `AbstractTexture#setFilter/setClamp/setUseMipmaps`,
`RenderTarget#setFilterMode` removed. `RenderTypes.MOVING_BLOCK_SAMPLER` added (sampler for moving blocks).

**Affected:** CustomRenderType (§6) — the old `BLOCK_SHEET_MIPPED` texture shard meant "block atlas with mipmaps".
No direct `GpuTexture`/`RenderPass` use in Capsule.

**Instructions:** pass a sampler as third argument of `withTexture` to keep mipmapped sampling:
`RenderTypes.MOVING_BLOCK_SAMPLER` if it is public, else
`() -> RenderSystem.getSamplerCache().getSampler(AddressMode.CLAMP_TO_EDGE, AddressMode.CLAMP_TO_EDGE, FilterMode.NEAREST, FilterMode.NEAREST, true)`
(imports `com.mojang.blaze3d.textures.AddressMode`, `com.mojang.blaze3d.textures.FilterMode`, `com.mojang.blaze3d.systems.RenderSystem`).
If a 2-argument `withTexture` exists, it uses the texture's own sampler; acceptable too.

## 8. Oh Hey, Another Rendering Rewrite — Block and Terrain Split

**What changed.** `RenderPipelines.SOLID` → `SOLID_BLOCK`/`SOLID_TERRAIN`, `CUTOUT` → `CUTOUT_BLOCK`/`CUTOUT_TERRAIN`,
`CUTOUT_MIPPED` removed, `TRANSLUCENT` → `TRANSLUCENT_TERRAIN` (no block variant), `TRIPWIRE` → `TRIPWIRE_BLOCK`/`TRIPWIRE_TERRAIN`.
`_TERRAIN` pipelines are for chunk sections (they read a per-section UBO, `DynamicUniforms$ChunkSectionInfo`);
`_BLOCK` ones are for standalone blocks drawn through a buffer source. `ChunkSectionLayer.CUTOUT_MIPPED` removed.

**Affected:** common/src/main/java/capsule/client/render/CustomRenderType.java:20 (`RENDERTYPE_CUTOUT_SHADER`) and :33
(`RENDERTYPE_TRANSLUCENT_SHADER`) — the ghost preview draws blocks immediately with a PoseStack, like moving blocks.

**Instructions:** in §6 use `CUTOUT_BLOCK` for GHOST_DEPTH and `TRANSLUCENT_MOVING_BLOCK` for GHOST, never a `_TERRAIN` pipeline.

private static void line(PoseStack.Pose pose, VertexConsumer c, float ax, float ay, float az, float bx, float by, float bz,
                         float r, float g, float b, float a, float width) {
    float nx = bx - ax, ny = by - ay, nz = bz - az;
    float len = Mth.sqrt(nx * nx + ny * ny + nz * nz);
    if (len < 1.0E-6F) { nx = 0; ny = 1; nz = 0; } else { nx /= len; ny /= len; nz /= len; }
    c.addVertex(pose, ax, ay, az).setColor(r, g, b, a).setNormal(pose, nx, ny, nz).setLineWidth(width);
    c.addVertex(pose, bx, by, bz).setColor(r, g, b, a).setNormal(pose, nx, ny, nz).setLineWidth(width);
}
